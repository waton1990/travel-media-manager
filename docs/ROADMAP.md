# 后续计划

这些是待讨论和验证的候选方向，不代表已实现功能或交付日期。优先级根据真实使用问题、兼容性反馈和维护能力调整。

## 公开试用基础

- 持续验证新 Mac 的下载、安装与升级体验。
- 扩大 macOS／iOS、设备型号、图库规模和存储设备的兼容性记录。
- 用合成数据补充演示和可复现问题，整理常见连接与索引错误。
- 改善公开版本的构建、依赖声明和发布检查。

## 归档体验候选项

- 为未知位置提供更容易核对的预览方式，并明确额外读取与缓存范围。
- 普通城市中的单项素材排除，帮助处理少数不可读项目或重名冲突。
- 明确设计后再评估续传、追加和重复素材处理，避免覆盖已有结果。
- 评估离线地点整理或显式联网查询选项。
- 根据实际需求评估英文界面和更多文件编码。

## 维护原则

继续保持源文件只读、范围明确、复制后校验和失败可解释。iOS 内部索引发生变化时，先验证新的分类与资源关系，再扩展支持。

商业化方式、App Store 版本或其他平台尚未确定。它们需要单独评估需求、技术限制和许可证，不能从这份清单推断已经承诺。

提出建议时，请说明实际场景、目前如何完成、卡在哪一步，以及怎样判断改进有用。反馈方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
