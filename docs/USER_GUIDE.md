# 使用说明

旅行素材管家将一次旅行的素材复制到同一个普通文件夹。以下例子中的名称、日期和文件名均为虚构示例。

## 安装与准备

查看 [Releases](https://github.com/waton1990/travel-media-manager/releases)，确认是否提供与你的 Mac 匹配的应用附件，并阅读该版本的安装说明和校验值。自动生成的 Source code 压缩包是源码，不能直接作为应用打开；从源码构建见 [README](../README.md#从源码构建)。

当前已有构建为 Apple Silicon 版本，只有本地临时签名，尚未完成 Apple 公证。测试包下载、安装和首次打开的系统提示处理见[安装说明](INSTALL.md)。请按提示类型区分处理，不关闭系统安全功能；也可以等待完成正式签名的版本再使用。

实际归档前，确认目标磁盘已连接、有足够空间，并先用少量非敏感素材熟悉流程。

## iPhone 数据线归档

1. **填写旅行信息。** 输入例如“海岸周末”，选择起止日期。日期范围包括首尾两天；旅行拍摄时区影响素材属于哪一天，请按实际行程核对。
2. **连接手机。** 先退出 iPhone 镜像，使用数据线连接、解锁手机，并按系统提示信任 Mac。选择“iPhone（数据线）”，点击“查找设备”，再选择手机。
3. **选择保存位置。** 点击“保存到”，在系统窗口选择 Mac 或外置硬盘上的父文件夹，无需手写地址。
4. **扫描素材。** 点击“扫描素材”。应用读取照片索引，在 Mac 上按日期和“由我拍摄”分类筛选；不会在这一步复制原片或创建旅行目录。
5. **选择地点。** 勾选需要的城市／地区。各组默认不选；“位置未知”展开后，根据文件名、拍摄日期和类型逐项选择。
6. **选择实况模式。** 默认“完整实况照片”；只需要静态原片时选择“仅静态照片”。独立视频保持正常导入。切换会重新计算文件数和大小，无需重扫或重复查询地点。
7. **核对预览。** 注意“素材数”和“实际文件数”的区别，并处理重名、不可读原件等阻止归档的提示。
8. **开始归档。** 接回同一部手机并保持解锁、连接。应用先显示“第一步：复制素材”，再显示“第二步：统一校验”。等到“归档完成”，再用“在 Finder 中打开”查看结果。

扫描后可以拔线查看结果和选择；归档前需要接回同一部手机。修改旅行名称、日期、时区、来源、保存位置或显式更换手机，会清空扫描与选择，需要重新扫描。

## 实况照片怎样保存

| 模式 | 保存内容 |
| --- | --- |
| 完整实况照片（默认） | 原始静态照片和配套短视频；配对及完整性校验通过后计为完成 |
| 仅静态照片 | 原始静态照片，不转换格式，不读取实况配套视频内容 |

一张实况照片加一段独立视频，在完整模式下通常是两项素材、三个文件；仅静态模式则为两项素材、两个文件。配套短视频不重复计为独立拍摄的视频。

当前支持已可靠识别的资源组合。扫描仍要求完整、可信的资源关联，选择仅静态模式不会自动放行资源缺失或关联异常的项目。

## 从相机卡或普通文件夹归档

选择“文件夹”来源，在系统窗口选择素材目录和保存位置，填写旅行名称和日期，再扫描预览、开始归档。软件递归扫描子文件夹，支持以下扩展名：

| 类型 | 扩展名 |
| --- | --- |
| 照片 | JPG、JPEG、HEIC、DNG、PNG、TIF、TIFF |
| 视频 | MP4、MOV、M4V |
| 音频 | AAC、M4A、WAV、MP3、AIFF |

扩展名被识别不保证每种编码或元数据都受支持。程序根据可读取的拍摄信息判断日期；没有可靠日期、或日期证据发生跨日冲突的素材不纳入，不用修改时间替代拍摄日期。LRF 等不支持的辅助文件忽略，原件保留。文件夹来源没有 iPhone 城市选择和实况模式开关。

## 结果目录

应用新建 `开始日期_旅行名称`，保留原文件名并平铺保存，例如：

```text
你选择的保存位置/
└── 2026-06-06_海岸周末/
    ├── DEMO_STILL_01.HEIC
    ├── DEMO_STILL_01.MOV
    └── DEMO_VIDEO_02.MOV
```

同一次归档只使用一个来源。不会覆盖已有目录、追加素材、自动去重或自动处理重名。相同完整文件名会阻止归档；HEIC 和 MOV 扩展名不同，不属于同名文件。

## 扫描速度、地点与隐私

iPhone 索引快照可能包含整个图库的元数据，在 Mac 本地筛选。因此，日期范围小不代表索引传输一定很快。应用优先使用手机的有效城市信息；缺少信息时会把坐标交给 Apple 补查，查询不上传照片或视频。无可用位置或补查失败的项目进入“位置未知”。详见[隐私说明](PRIVACY.md)。

只在 iCloud 中的原件不会自动下载；“由我拍摄”依赖手机生成的索引，缺失索引不直接等同于“不是本人拍摄”。iPhone 模式不读取独立音频、语音备忘录、隐藏或已删除项目，也不恢复相册或编辑历史。

## 常见提示

| 提示 | 处理方法 |
| --- | --- |
| 没有可归档素材 | 核对日期、时区和来源；iPhone 扫描后需要主动选择地点或未知位置素材 |
| 手机未连接或不允许读取 | 核对数据线、解锁和信任状态，退出镜像后重新扫描 |
| 照片索引正在变化 | 先等手机后台整理完成，再扫描；复制准备成功后仅有索引更新不会改变本次已确认选择 |
| 原件或配套视频不可读 | 查看该项目的原因；本版本不会从 iCloud 补下载或把不完整实况当作成功 |
| 同名文件冲突 | 调整来源或选择范围；程序不会覆盖、擅自改名 |
| 旅行文件夹已存在 | 更换旅行名称或保存位置；本版本不追加已有结果 |
| 保存位置或空间有问题 | 选择已连接、可写且有足够空间的目标磁盘 |

普通城市按整组选择；组内有阻塞项目时目前不能单独排除其中某一项。未知位置列表支持逐项选择，但没有缩略图预览。

## 取消与失败

点击“取消任务”后等待任务停止，再关闭应用或拔线。iPhone 复制阶段尚未统一校验，已复制文件不会提前计为成功；程序清理能够确认属于本次操作的暂存。校验阶段失败时保留此前已校验的完整素材，不能确认身份或被外部改动的文件不会误删。

当前没有断点续传。失败后查看提示和结果目录，重新归档时使用新的旅行名称或保存位置。只有计划内文件全部完成复制与校验，才显示“归档完成”。

需要反馈问题时，请先阅读[贡献说明](../CONTRIBUTING.md)，不要上传私人原片或未经处理的日志。
