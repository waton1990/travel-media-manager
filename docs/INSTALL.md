# 安装社区测试版

本说明适用于 **0.3.1（build 10）Apple Silicon 社区预览包**，界面为简体中文。发行包已完成 Developer ID Application 签名和 Apple 公证，并附有公证票据。源码声明最低 macOS 13，但这不代表已经在所有旧系统验证；Intel Mac 不在当前测试包支持范围内。

## 下载与安装

1. 打开本项目的 [Releases](https://github.com/waton1990/travel-media-manager/releases)，找到 **v0.3.1**，阅读发布说明。
2. 在附件中选择 `TravelMediaManager-0.3.1-build10-arm64.zip`。若尚未提供此附件，表示该应用包尚未发布，请等待。**Source code (zip / tar.gz) 是源码，不是可运行应用。**
3. 确认下载来自上述仓库，文件名与版本一致。如需校验，可在“终端”运行 `shasum -a 256`，输入一个空格后把下载的 ZIP 拖入窗口，按回车，将结果与同一 Release 公布的 SHA-256 比较。校验值不一致时不要打开。
4. 双击 ZIP 解压，将“旅行素材管家.app”拖入“应用程序”，再双击打开。应用包已带 USB 运行组件，不需要另装 Python 或 uv。

## 首次打开时的系统提示

从浏览器下载后，macOS 可能提示这是从互联网下载的应用。核对应用名称、开发者和来源后，按系统提示打开即可。正常安装本版发行包不需要为应用添加安全例外，也不需要关闭 Gatekeeper 或 SIP。Apple 公证是分发安全检查，不代替设备兼容性或归档功能测试。[苹果官方说明](https://support.apple.com/zh-cn/102445)

如果仍提示“无法验证开发者”“Apple 无法检查 App”，请先确认下载的是本仓库的 **0.3.1 build 10** 应用附件，并核对 SHA-256。旧版 0.3.0 build 9 和自行构建的临时签名包不具备本版发行包的公证状态。

若提示“将损坏你的电脑”、发现恶意软件、“App 已损坏”，或校验值不一致，请停止打开，重新核对来源并反馈错误；不要使用绕过系统安全检查的命令。受组织管理的 Mac 还可能受额外安装策略限制。

## 第一次归档

先用少量**已有备份**的素材验证自己的设备和保存磁盘。iPhone 模式需退出 iPhone 镜像，接上数据线、解锁手机并信任 Mac；保持连接直到复制和校验完成。文件夹模式不需要连接手机。

照片和视频通过 USB 或本地文件系统复制，不通过 iCloud 导入。缺少可用城市信息时，应用可能将拍摄坐标发送给 Apple 查询城市；不上传照片或视频内容。使用前阅读[隐私说明](PRIVACY.md)，完整步骤见[使用说明](USER_GUIDE.md)。

问题可提交到 [Issues](https://github.com/waton1990/travel-media-manager/issues)。请写明版本、系统、机型和错误文字，不要附私人原片、照片索引或未脱敏日志。
