# 安装社区测试版

本说明适用于 **0.3.0（build 9）Apple Silicon 测试包**，界面为简体中文。应用使用本地临时签名，**没有 Developer ID 签名，也未经过 Apple 公证**。源码声明最低 macOS 13，但这不代表已经在所有旧系统验证；Intel Mac 不在当前测试包支持范围内。

## 下载与安装

1. 打开本项目的 [Releases](https://github.com/waton1990/travel-media-manager/releases)，找到 **v0.3.0**，阅读发布说明。
2. 在附件中选择 `TravelMediaManager-0.3.0-build9-arm64.zip`。若尚未提供此附件，表示该应用包尚未发布，请等待。**Source code (zip / tar.gz) 是源码，不是可运行应用。**
3. 确认下载来自上述仓库，文件名与版本一致。如需校验，可在“终端”运行 `shasum -a 256`，输入一个空格后把下载的 ZIP 拖入窗口，按回车，将结果与同一 Release 公布的 SHA-256 比较。校验值不一致时不要打开。
4. 双击 ZIP 解压，将“旅行素材管家.app”拖入“应用程序”，再双击打开。应用包已带 USB 运行组件，不需要另装 Python 或 uv。

## 首次打开时的系统提示

对于“无法验证开发者”或“Apple 无法检查 App 是不是包含恶意软件”这类提示，先核对来源和文件完整性。只有你确认信任这份测试包、接受未公证状态时，才考虑为**这个应用**添加例外：

1. 先尝试打开应用，然后进入“系统设置”→“隐私与安全性”。
2. 在与“旅行素材管家”对应的拦截提示旁点击“仍要打开”。
3. 再次确认应用名称，按系统提示选择“打开”并完成必要验证。

这采用苹果说明中的单个应用例外流程，不要求关闭 Gatekeeper、SIP 或其他系统保护。具体措辞可能随系统版本变化；受组织管理的 Mac 也可能不允许添加例外。若没有相应按钮或仍无法打开，请停止并反馈，不要尝试绕过命令。[苹果官方：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)

**如果提示“将损坏你的电脑”、发现恶意软件，或“App 已损坏”，不要按上述例外流程强行打开。** 停止使用，核对发布说明并报告错误；损坏或校验不一致时可重新从本仓库下载，仍有问题则等待修复。苹果说明这些提示可能涉及恶意内容、授权撤销、文件损坏或篡改。[苹果对不同警告的说明](https://support.apple.com/zh-cn/102445)

## 第一次归档

先用少量**已有备份**的素材验证自己的设备和保存磁盘。iPhone 模式需退出 iPhone 镜像，接上数据线、解锁手机并信任 Mac；保持连接直到复制和校验完成。文件夹模式不需要连接手机。

照片和视频通过 USB 或本地文件系统复制，不通过 iCloud 导入。缺少可用城市信息时，应用可能将拍摄坐标发送给 Apple 查询城市；不上传照片或视频内容。使用前阅读[隐私说明](PRIVACY.md)，完整步骤见[使用说明](USER_GUIDE.md)。

问题可提交到 [Issues](https://github.com/waton1990/travel-media-manager/issues)。请写明版本、系统、机型和错误文字，不要附私人原片、照片索引或未脱敏日志。
